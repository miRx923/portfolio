Measuring Prompt Robustness in Slovak Large Language Models

A benchmark and Streamlit application for evaluating how language models respond to semantically equivalent variations of Slovak instructions.

Year: 2026 Focus: Slovak prompt sensitivity Metric: POSIX Prompt Sensitivity Index Output: Benchmark, datasets, experiments, web interface
Thesis PDF Source Code Live Demo

Problem & Motivation

Large language models can produce different answers when a prompt is paraphrased, contains a spelling mistake, omits diacritics, or uses a different tone — even when the intended meaning remains unchanged. For a relatively low-resource language such as Slovak, this instability is poorly understood, since most existing robustness benchmarks focus on English or other high-resource languages.

This project investigates how robust current language models are to such linguistic variations in Slovak, and whether Slovak-focused models behave more reliably than multilingual or European-focused alternatives when faced with realistic, everyday prompt variation.

Dataset Overview

The benchmark is built on four datasets, each isolating a different type of prompt variation while preserving the original intent of the instruction.

Dataset category What it tests
Paraphrases Whether meaning-preserving reformulations change the model's output
Spelling & grammatical errors Robustness to typos and grammatical mistakes
Mixture Combined linguistic perturbations occurring together
Tonality The effect of politeness level and instruction style

Methodology

Each model was evaluated across all four datasets using an identical prompting protocol. For every original instruction, the model's response was compared against its response to each perturbed variant. Sensitivity was then quantified using the POSIX (Prompt Sensitivity Index) metric, which measures how much a model's output changes under semantically equivalent prompt variations — lower POSIX values indicate greater robustness.

Models evaluated included Slovak-focused models, European-focused multilingual models, and broader multilingual models, allowing a direct comparison of how language specialization relates to robustness. Due to hardware constraints, the evaluation focused on smaller models (under roughly 7B parameters).

Spelling and grammatical errors produced the largest changes in model behavior, while syntactic and pragmatic-stylistic changes (such as politeness) generally produced smaller effects. Slovak-focused models generally showed lower sensitivity to prompt variations than multilingual models, which were more affected by linguistic perturbations.

Key Findings

  • Developed a dedicated benchmark for Slovak prompt sensitivity, covering four distinct types of linguistic perturbation.
  • Compared Slovak, European-focused, and multilingual language models under an identical evaluation protocol.
  • Analyzed lexical, syntactic, structural, and pragmatic prompt variations separately.
  • Found the highest sensitivity for grammatical errors and spelling mistakes across nearly all models.
  • Observed greater robustness in Slovak-focused models compared to broader multilingual models.
  • Implemented a graphical interface for running and evaluating experiments interactively.

Limitations & Lessons Learned

  • Experiments focused on smaller models due to hardware constraints, so findings may not generalize directly to much larger models.
  • Overall lower model quality in Slovak can complicate interpretation of sensitivity scores, since a model may produce a stable but consistently incorrect answer.
  • Further work could examine larger models, quantization effects, language-specific tokenizers, and additional Slovak datasets.
  • Building a usable interface alongside the experiments highlighted the value of tooling, not just raw results, for communicating research outcomes.
