Personal Project · RAG

LLM ChatBot - Local & Cloud Document Assistant

A Streamlit-based multi-model document assistant that answers questions about uploaded PDF, DOCX, and TXT files. The application implements a retrieval-augmented generation pipeline with local Ollama embeddings, semantic search, and either Gemini or locally executed GGUF language models.

Python Streamlit RAG Ollama Gemini API llama.cpp GGUF NumPy PyPDF2

Key Features:

  • Implemented a document ingestion pipeline for TXT, PDF, and DOCX files using PyPDF2 and python-docx.
  • Built a RAG pipeline that splits documents into sentence-based chunks of up to 1,000 characters.
  • Generated embeddings locally with Ollama and the mxbai-embed-large embedding model.
  • Implemented semantic retrieval with cosine similarity in NumPy, selecting the top 5 relevant document chunks for each question.
  • Integrated Gemini 2.5 Flash-Lite and local GGUF models: Gemma 3 4B, Gemma 3 1B, and EuroLLM 1.7B Instruct.
  • Built a multi-session Streamlit interface with per-chat model selection, editable chat names, history management, and RAG vault reset controls.
  • Implemented ChatML prompt formatting and explicit cleanup of local llama.cpp resources when changing models or chats.

Theses & Research

Bachelor's Thesis · 2024

Prompt Engineering for Sentiment Analysis Using Large Language Models

This thesis investigates the use of prompt engineering techniques for sentiment analysis with large language models. Seven transformer-based models and four prompting strategies were evaluated on 10,000 IMDb movie reviews. The best result was achieved with the Orca-2 7B model using Zero-Shot Chain-of-Thought prompting, reaching a classification accuracy of 94.6%.

Sentiment Analysis Prompt Engineering Python Large Language Models HF Transformers NLP

Key Contributions:

  • Comparison of sentiment analysis with and without prompt engineering
  • Evaluation of seven transformer-based language models
  • Comparison of Zero-Shot, One-Shot, Few-Shot, and Chain-of-Thought prompting
  • Experimental evaluation on the IMDb movie review dataset
  • Identification of Orca-2 7B with Zero-Shot Chain-of-Thought as the best-performing approach
Master's Thesis · 2026

Robustness of Large Language Models to Slovak Prompt Variations

This thesis presents a Slovak-language benchmark for measuring the sensitivity of large language models to semantically equivalent prompt variations. Four datasets were created to evaluate paraphrases, spelling and grammatical errors, changes in instruction structure, and different levels of politeness. Model robustness was quantified using the POSIX Prompt Sensitivity Index.

Python Large Language Models Slovak NLP Benchmarking POSIX HF Transformers Streamlit

Key Findings:

  • Development of a dedicated benchmark for Slovak prompt sensitivity
  • Comparison of Slovak, European-focused, and multilingual language models
  • Analysis of lexical, syntactic, structural, and pragmatic prompt variations
  • Highest sensitivity observed for grammatical errors and spelling mistakes
  • Greater robustness observed in Slovak-focused models than in multilingual models
  • Implementation of a graphical interface for running and evaluating experiments
